# archify
- **archify** (`.claude/skills/archify/SKILL.md`) - Maps `design.json` artifacts to standardized visual diagram format.
Trigger: `/archify`

## Objective
Take raw `design.json` architectural state, process it against `diagram-templates/`, and inject mandatory `artifact_id` metadata.

## Usage
Invoked within a skill directory that contains a `design.json` file.
