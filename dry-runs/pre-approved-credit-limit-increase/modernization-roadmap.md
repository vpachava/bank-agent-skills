# Modernization Roadmap: T24 R18 to R24

| Phase | Timeline | Primary Focus | Key Deliverables |
| :--- | :--- | :--- | :--- |
| **Discovery** | Weeks 1-2 | AA/AC Inventory, OFS Mapping | Inventory Catalog, API Contract |
| **Foundation** | Weeks 3-5 | Middleware Proxy, API Normalization | Normalized Proxy, Standardized API |
| **Migration** | Weeks 6-10 | AA-to-AC Migration (Data) | Migrated Product Code Data |
| **Integration**| Weeks 11-14 | Event-Driven Architecture (EDA) | Event Emitters, EDA Middleware |
| **Hardening** | Weeks 15-16 | UAT, Performance Tuning | Finalized R24 Environment |

## Critical Path Items
1. Domain API specification (Must be concurrent with Phase 1 mapping).
2. AA to AC data migration validation (Must be completed before Phase 3).
3. Middleware event listener setup (Must be operational before EDA go-live).
