# /archify

## When to apply
Use as the visual post-processor for any architectural design process. Every time you generate an HLD or LLD, use `/archify` to ensure the visual representation of your design is programmatically generated from the data, not drawn manually.

## Process
1. **Input:** Takes the `design.json` artifact generated by `/hld-generator` or `/lld-generator`.
2. **Logic:** Maps identified components to standard banking iconography (based on BIAN domain mappings).
3. **Output:** Generates canonical Mermaid.js source code for rendering in GitHub PRs and architecture documentation.

## Banking Standards Enforcement
- **Iconography:** Ensures all core banking containers, regulated zones, and integration seams are rendered with standardized symbols.
- **Traceability:** Automatically appends an `artifact_id` metadata tag to the generated Mermaid block.
