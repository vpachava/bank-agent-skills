# Pilot Program Feedback System

This directory contains the necessary templates and structures to collect structured feedback, success stories, and case studies from early adopters of the `bank-agent-skills` library.

---

## 1. Feedback Form (`feedback-form.md`)
Please copy this content into a GitHub Issue template or a Google Form to gather structured feedback from pilot users.

```markdown
# bank-agent-skills Pilot Feedback

1. **How did you discover `bank-agent-skills`?** ________________
2. **What was your first architectural use case?** ________________
3. **Which skills did you find most useful?** ________________
4. **What was the biggest benefit to your workflow?** ________________
5. **What is one thing that could be improved?** ________________
6. **Would you recommend this tool to other architects? (1-10)**: __
7. **Permission to use your feedback as a testimonial?**: (Yes/No)
```

## 2. Testimonial Template (`testimonial-template.md`)
Use this to capture short, impactful quotes from successful pilots.

```markdown
# Testimonial: [User Name / Organization]

" [Insert Quote Here] "

- **Project:** [Project Name]
- **Key Skill Used:** [e.g., /hld-generator, /evidence-gate]
- **Impact:** [e.g., "Reduced design time by 40%"]
```
