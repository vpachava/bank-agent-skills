# /industries/government

## Overview
Architectural framework for federal, defense, and public sector agencies. Enforces NIST SP 800-53 (Low/Moderate/High) security controls, FISMA compliance, and FedRAMP cloud authorization baselines.

## Process
1. **Security Categorization (FIPS 199):** Classify information systems based on confidentiality, integrity, and availability impact.
2. **NIST 800-53 Control Allocation:** Map architectural components to specific control families (AC, AU, SC, SI).
3. **FedRAMP Boundary Definition:** Establish agency-specific cloud trust boundaries with continuous monitoring and automated evidence collection.
