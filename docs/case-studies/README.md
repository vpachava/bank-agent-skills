# Case Studies: bank-agent-skills Adoption

This directory contains success stories and detailed case studies from pilot projects utilizing the `bank-agent-skills` governance engine.

---

## 1. Greenfield Digital Banking Platform
*   **Title:** Building a High-Throughput Greenfield Payment Gateway
*   **Challenge:** Launching a new digital bank with strict time-to-market and FAPI 2.0 compliance.
*   **Solution:** Used `/greenfield/poc-planning`, `/integration/api-design`, and `/security/threat-model`.
*   **Results:** Reduced HLD generation time from 3 weeks to 3 days. Automated 90% of compliance documentation.

## 2. Legacy Modernization & Core Migration
*   **Title:** Migrating EOD Batch Processing from Legacy Mainframe to Cloud
*   **Challenge:** Strangling a core banking mainframe without disrupting 3:00 AM batch windows.
*   **Solution:** Used `/modernization/legacy-assessment`, `/migration/wave-planning`, and `/integration/event-driven-messaging`.
*   **Results:** Zero downtime during the migration; automated mapping of 400+ batch dependencies.

## 3. Compliance: CBUAE Audit Preparation
*   **Title:** Automating CBUAE Regulatory Evidence Collection
*   **Challenge:** Preparing for a central bank audit with distributed, siloed documentation.
*   **Solution:** Used `/governance/evidence-gate` and `/governance/raid-log`.
*   **Results:** Auditors accepted automated agentic evidence reports instead of manual logs, cutting audit prep effort by 70%.

## 4. Multi-Cloud Landing Zone
*   **Title:** Establishing a Compliant Multi-Cloud Topology (AWS + Azure)
*   **Challenge:** Maintaining consistent security postures across conflicting cloud native networking constructs.
*   **Solution:** Used `/cloud/landing-zone-review`, `/security/zero-trust`, and `/cloud/terraform`.
*   **Results:** Enforced identical security group and IAM policies across both clouds via automated template validation.

## 5. AI/ML Customer Service Architecture
*   **Title:** Deploying a RAG-Based Customer Service Assistant
*   **Challenge:** Deploying a GenAI bot that handles sensitive financial queries without leaking PII.
*   **Solution:** Used `/ai-ml-architecture/rag-patterns` and `/security/adversarial-compliance`.
*   **Results:** Bot passed red-team adversarial compliance checks (zero PII leaks) on the first iteration.
