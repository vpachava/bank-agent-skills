# AI/ML Skill Specs & Compliance

## Skill: MLOps Design
- TDD Requirement: Validate deployment pipeline configurations.
- Regulatory: Audit logs for model promotion.

## Skill: RAG Patterns
- TDD Requirement: Test retrieval relevance and context quality.
- Regulatory: PII redaction on vectors.

## Skill: Model Governance
- TDD Requirement: Validate drift detection thresholds.
- Regulatory: Model provenance and lineage.

## Skill: AI Ethics Review
- TDD Requirement: Test for fairness/bias in model output samples.
- Regulatory: Explicit bias mitigation documentation.

## Skill: Feature Store Design
- TDD Requirement: Validate feature consistency (offline/online).
- Regulatory: Data residency compliance.

## Skill: ML Pipeline Architecture
- TDD Requirement: Validate pipeline orchestration steps.
- Regulatory: Reproducibility assurance.
