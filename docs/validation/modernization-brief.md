# Modernization Pilot: Monolith to Microservice

## Goal
Convert monolithic 'Card Management' module into a microservice using `bank-agent-skills` to demonstrate architectural refactoring.

## Scope
- Extract Card Management logic from monolith.
- Define service contract (API/Event).
- Implement service orchestration and deployment patterns.

## Success Metrics
- API contract coverage.
- Deployment frequency improvement.

## Compliance Requirements
- Data residency: Microservice must adhere strictly to on-prem data rules.
- Security: Mutual TLS between services.
