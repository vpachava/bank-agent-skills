# Greenfield Pilot: Credit Limit Increase

## Goal
Implement a template-driven credit limit increase feature using `bank-agent-skills` to demonstrate efficiency gains (time-to-resolution).

## Scope
- Define API schema for limit increase request/response.
- Create automated test suite for validation logic.
- Document compliance requirements within the ADR.

## Success Metrics
- Time per endpoint definition vs baseline.
- Compliance gaps caught (should be 0 post-agent).

## Compliance Requirements
- CBUAE-align credit decisioning logic.
- PII scrubbing in logs.
